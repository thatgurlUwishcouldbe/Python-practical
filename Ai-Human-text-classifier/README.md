# AI Human Text Classifier

A course project for IT 1322 Big Data Analytics. The project explores whether a text sample was written by a human or generated by artificial intelligence.

## Dataset

The project requires `AIHumanDataset.csv`, provided with the course materials. The dataset is not included in this repository. Download it separately, then upload it to the Colab session before running the notebook.

The CSV contains:

- `text`: the text sample
- `generated`: the class label
  - `0`: Human-written
  - `1`: AI-generated

## Project Tasks

- Analyze the dataset and class distribution.
- Extract and normalize statistical text features.
- Visualize the features using parallel coordinates.
- Train Decision Tree, K-Nearest Neighbors (K-NN), and Neural Network classifiers.
- Evaluate and compare the classifiers using accuracy, precision, recall, F-measure, and confusion matrices.
- Document the results in a final report.

## Tools

- Python in Google Colab
- Weka for the Neural Network classifier
- Microsoft Word for the final report

## Running the Project

1. Open the project notebook in Google Colab.
2. Upload `AIHumanDataset.csv` to the Colab session.
3. Run the notebook cells in order.
4. Use the generated results and Weka outputs in the final report.
